# 스마트 웨이팅 시스템

시설 내 콘텐츠별 실시간 이용 현황과 예상 대기 시간을 시각적으로 제공하여 사용자의 자발적인 혼잡 분산을 돕는 프론트엔드 프로젝트입니다.

## 실행 방법

`index.html`을 브라우저로 열면 됩니다.

## 페이지 구성

- `index.html`: 모바일 예약 현황 화면
- `ticket.html`: 대기표 등록 화면
- `info.html`: 서비스 안내 화면
- `desktop.html`: 컴퓨터용 현황판 화면

## 파일 구조

- `css/styles.css`: 전체 디자인
- `js/data.js`: 콘텐츠 기본 데이터
- `js/waiting.js`: 대기 인원, 예상 시간, 입장 시각 계산
- `js/ui.js`: 화면 갱신, 메뉴, 대기표 등록 동작
- `js/app.js`: 앱 시작점
- `assets/apple-logo.png`: 임시 로고 이미지
- `assets/apple-content.jpg`: 임시 콘텐츠 이미지

## 핵심 공식

- 실시간 대기 인원 = 전체 예약 인원 - 콘텐츠 이용 완료 횟수
- 예상 대기 시간 = 실시간 대기 인원 x 기기별 평균 이용 시간
- 예상 입장 시각 = 현재 시각 + 남은 대기 시간
